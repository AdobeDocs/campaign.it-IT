# lookupNamespaceURI

È stata eseguita una ricerca nell’URI dello spazio dei nomi collegato al prefisso specificato.

```text
lookupNamespaceURI (prefix)
```

## Parametri

**prefisso** Prefisso.

## Valore restituito

URI dello spazio dei nomi o stringa vuota se non trovata.

## Funzioni

**Metodo di classe:** [DOMNode](c-domnode.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
