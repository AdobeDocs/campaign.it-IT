# RegisterExternalInstance

Approva un’istanza di tracciamento su un server relay per i server di reindirizzamento (impostando l’identificatore di database).

```text
RegisterExternalInstance ( String login, String instanceName, String dbId, Boolean saveParams )
```

## Parametri

Accesso al server di inoltro **login**

**instanceName** Nome dell&#39;istanza da approvare

**dbId** Identificatore di database per il cliente che esegue una consegna

**saveParams** Opzioni di salvataggio se riuscite

## Valore/i restituito/i

Nessuno.

**Schema:** [nms:trackingUrl](s-nms-trackingurl.md)

Sì
