# Guida alla migrazione E4X

L’estensione E4X per il supporto nativo di XML in JavaScript viene progressivamente abbandonata da Mozilla. Adobe Campaign ha fatto un uso intensivo di questa estensione e si sta preparando a migrare a una soluzione alternativa.

Scopo di questa guida è facilitare la migrazione delle configurazioni esistenti o lo sviluppo di nuove configurazioni descrivendo le soluzioni sostitutive.

Il vecchio e il nuovo sistema coesistono, l&#39;attuale versione di Adobe Campaign è sempre compatibile con E4X, ma le nuove configurazioni non devono essere sviluppate con l&#39;estensione E4X.

Promemoria: E4X aggiunge un tipo di codice XML di JavaScript che può essere creato direttamente dal programma di origine:

```text
var doc = <xml> ... </xml>
```

o da una stringa:

```text
var doc = new XML ("<xml>...</xml>")
```

Può quindi essere manipolato con un’API specifica:

```text
element.@id element.where
```

## Tipo XML

Il tipo &quot;xml&quot; nativo è sostituito da un&#39;API DOM. Si tratta di tipi [DOMDocument](c-domdocument.md) , [DOMElement](c-domelement.md) , [DOMNode](c-domnode.md) ... le operazioni seguenti sono equivalenti a quelle più comuni:

> **E4X:**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM:**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X:**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM:**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X:**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM:**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> o
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

I documenti XML in un JavaScript devono essere sostituiti. Quando questo documento deve essere utilizzato per una funzione nativa o una chiamata SOAP che trasmette un documento XML in un parametro, puoi trasmettere direttamente un JXON. Verrà automaticamente trasformato in un documento XML (DOMDocument). In caso contrario, è sempre possibile passare tramite un oggetto JXON, ma è necessaria una conversione esplicita utilizzando la funzione [DOMDocument.fromJXON](m-domdocument-fromjxon.md).

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

Esempio di equivalenza tra la sintassi XML e JXON:

> **E4X:**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON:**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

Per ulteriori informazioni sulla sintassi JXON, consulta la pagina Utilizzo di XML.

## Chiamate SOAP

Questi metodi di SOAP devono eseguire le proprietà dell&#39;oggetto NLWS. L’ID JavaScript dello schema viene creato dallo spazio dei nomi e dal nome che inizia con un maiuscolo. Lo schema nms:delivery, ad esempio, avrà nmsDelivery come ID JS.

> **Vecchio:**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **Nuovo:**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## Metodi di SOAP JavaScript

Per ricevere un documento XML i cui parametri sono in formato DOM anziché in formato E4X, è necessario aggiungere nello schema l&#39;attributo dom=&quot;true&quot;.

## Stringhe a più righe

L&#39;utilizzo di XML per creare stringhe su più righe deve essere sostituito da una concatenazione di stringhe dimenticando di aggiungere la fine della riga \\n.

> **Vecchio:**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **Nuovo:**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## Gestione dei contenuti

Durante l’anteprima è necessario attivare l’opzione DOM sul modello di pubblicazione o dal modello JavaScript. Per una trasformazione XSL con pre-elaborazione JavaScript, è necessario attivare anche l’opzione DOM (finestra aggregatore).
