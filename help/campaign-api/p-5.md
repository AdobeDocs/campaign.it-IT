# Utilizzo delle date

Questo capitolo descrive le funzioni da utilizzare per manipolare le date nei programmi JavaScript eseguiti sul server (flusso di lavoro, JSSP, ecc.).

## Date e fusi orari

In JavaScript, le date vengono memorizzate in formato UTC. Ciò significa che devi preoccuparti solo dei fusi orari per la costruzione delle date o la conversione in stringhe di testo per la visualizzazione o la memorizzazione interna. Per la conversione delle date, sono disponibili due categorie di funzioni:

* le funzioni della libreria JavaScript (date.toString(), date.toLocaleString(), date.getHours(), ...),
* le funzioni della piattaforma Adobe Campaign ( [formatDate(date, format)](f-formatdate.md) ).

Per convenzione, il primo utilizza il fuso orario della macchina, mentre l’ultimo utilizza un fuso orario a seconda del contesto: in genere quello dell’operatore corrente, ma questo comportamento può essere modificato per esportazioni o flussi di lavoro, ad esempio.

## Ottieni data corrente

Esistono due modi per ottenere la data corrente in JavaScript:

* new Date() crea un nuovo oggetto Date inizializzato con la data corrente. La data coincide con l&#39;ora del computer in cui viene eseguito lo script.
* [getCurrentDate()](f-getcurrentdate.md) restituisce la data corrente in base all&#39;ora del server di database.

La funzione [getCurrentDate()](f-getcurrentdate.md) è preferibile alla prima soluzione, in particolare quando la data deve essere confrontata con altre date del database o scritta nel database. Questo metodo riduce il rischio di discrepanze (fino a diversi minuti) collegate alle differenze di tempo tra il server dell&#39;applicazione e il server del database

## Visualizzazione data

La conversione di una data in una stringa di caratteri a scopo di visualizzazione utilizza la funzione [formatDate](f-formatdate.md).

## Conversione di una data da un documento XML

Le date memorizzate in un documento XML proveniente dal database di Adobe Campaign sono in formato testo: possono essere convertite utilizzando la funzione [parseTimeStamp](f-parsetimestamp.md). In genere si tratta di documenti XML restituiti dal metodo [ExecuteQuery](sm-querydef-executequery.md). Esempio:

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## Inserimento di una data in un documento XML

Per scrivere una data in un attributo XML, salvare un documento (metodo [Write](sm-session-write.md)) o inserire una data letterale nell&#39;espressione di una query, è necessario convertire la data nel formato ISO8601. Nella libreria di funzioni xtk:shared/nl.js è disponibile un metodo per convertire una data in questo formato: il metodo NL.XTK.formatDateTime(date). La libreria può essere caricata utilizzando la funzione loadLibrary:

```javascript
loadLibrary("xtk:shared/nl.js")
```

o utilizzando la direttiva page in caso di pagina JavaScript dinamica (JSSP):

```xml
<%@ page import="xtk:shared/nl.js" %>
```

Avviso: impossibile utilizzare loadLibrary per tutti gli script. Ad esempio, non puoi modificare una libreria di funzioni JavaScript in uno script di personalizzazione e-mail. Esempio: questo esempio mostra la costruzione di una query utilizzando una data letterale.

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
