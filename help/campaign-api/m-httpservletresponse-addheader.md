# addHeader

Aggiunge un’intestazione HTTP aggiuntiva alla risposta.

```text
addHeader (nom, valeur)
```

## Parametri

**nom** Nome dell&#39;intestazione da aggiungere.

**valeur** Valore dell&#39;intestazione aggiunta.

## Valore restituito

Nessuno.

**Metodo di classe:** [HttpServletResponse](c-httpservletresponse.md)
