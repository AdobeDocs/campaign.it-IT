# fileSize

Restituisce la dimensione di un file in byte.

```text
fileSize (filename)
```

## Parametri

**nomefile** Il nome completo del file.

## Valore restituito

Restituisce la dimensione del file o -1 se si è verificato un errore (ad esempio, se il file non è stato trovato).

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
