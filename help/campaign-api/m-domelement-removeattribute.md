# removeAttribute

Eliminare un attributo.

```text
removeAttribute (name)
```

## Parametri

Nome attributo **name**.

## Valore restituito

Nessuno.

## Osservazioni

Il metodo non ha alcun effetto se l&#39;elemento non ha un attributo con questo nome.

**Metodo di classe:** [DOMElement](c-domelement.md)

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione

* Metodo SOAP

* Flusso di lavoro
