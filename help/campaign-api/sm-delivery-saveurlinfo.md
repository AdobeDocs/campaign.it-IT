# SaveUrlInfo

Salva gli URL di questa consegna come modelli URL.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Parametri

**insUrlList** Elenco di nuovi URL (non associati a un modello di URL)

**updUrlList** Elenco di modelli URL da aggiornare

## Valore/i restituito/i

Nessuno.
