# DeleteResult

Cancella i risultati di una o più attività.

```text
DeleteResult ( String workflowId, String activityName )
```

## Parametri

**workflowId** Identificatore o nome interno del workflow.

**activityName** Nome delle attività di cui si desidera cancellare i risultati

## Valore/i restituito/i

Nessuno.
