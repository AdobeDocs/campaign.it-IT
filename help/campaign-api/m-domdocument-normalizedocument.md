# normalizeDocument

Normalizza il documento: i riferimenti di entità vengono sostituiti e i nodi di testo adiacenti vengono fusi.

```text
normalizeDocument ()
```

## Parametri

Nessuno.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
