# applyXslFromFile

Trasforma un documento XML utilizzando un foglio di stile XSL.

```text
applyXslFromFile (xslEntity, filename)
```

## Parametri

**xslEntity** nome del foglio di stile XSL memorizzato nel database.

**nomefile** Nome del file XML da trasformare.

## Valore restituito

Documento XML sotto forma di stringa di caratteri dopo la trasformazione.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
