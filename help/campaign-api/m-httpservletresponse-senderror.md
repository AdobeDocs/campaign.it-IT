# sendError

Restituisce una risposta di errore utilizzando il codice di errore passato come parametro.

```text
sendError (errorCode)
```

## Parametri

**errorCode** Il codice di errore HTTP.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponibile in:**

* JSSP
* WebApp
