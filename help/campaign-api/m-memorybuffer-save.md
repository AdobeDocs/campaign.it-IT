# salva

> Avvertenza:
>
> L&#39;accesso tramite API di file è limitato alle cartelle **var**, **sftp** e temporanee di Adobe Campaign.

Salva il contenuto del buffer in un file.

```text
save (filename)
```

## Parametri

**nomefile** Nome del file da salvare.

## Valore restituito

Nessuno.
