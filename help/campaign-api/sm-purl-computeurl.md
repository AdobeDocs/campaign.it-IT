# UrlCalcolo

Genera l’URL per accedere a questo pURL

```text
[ String url, String exampleUrl ] = ComputeUrl ( XML purl )
```

## Parametri

**purl** Il purl corrente.

## Valore/i restituito/i

**url** URL (tecnico)

**exampleUrl** URL contenente dati fittizi (per la visualizzazione)
