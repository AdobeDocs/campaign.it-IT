# SwitchValuesAndAliases

Converti un valore in un alias e viceversa.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Parametri

**enums** insieme delle enumerazioni da convertire.

Modalità di conversione **mode**: deve essere &#39;ValuesToAliases&#39; o &#39;AliasesToValues&#39;.

## Valore/i restituito/i

Nessuno.

## Funzioni

**Schema:** [xtk:enum](s-xtk-enum.md)

**Statico:**

Sì
