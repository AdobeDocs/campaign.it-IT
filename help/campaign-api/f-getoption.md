# getOption

Restituisce il valore di un&#39;opzione nella tabella delle opzioni.

```text
getOption (name [, useCache ])
```

## Parametri

**nome** Nome dell&#39;opzione.

**useCache** Utilizza la cache dei valori delle opzioni (per impostazione predefinita non viene utilizzata).

## Valore restituito

Il valore dell’opzione se esiste, altrimenti non definito. Il tipo di valore dipende dal tipo dell’opzione.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
