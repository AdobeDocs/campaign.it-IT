# replaceChild

Sostituire un nodo.

```text
replaceChild (newChild, oldChild)
```

## Parametri

**newChild** nodo da inserire.

**oldChild** nodo da sostituire.

## Valore restituito

Nodo sostituito.

**Metodo di classe:** [DOMNode](c-domnode.md)

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione

* Metodo SOAP
* WebApp
* Flusso di lavoro
