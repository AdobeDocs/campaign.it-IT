# fileIsRelative

Specifica se un nome di file è un nome relativo.

```text
fileIsRelative (fileName)
```

## Parametri

**nomeFile** Nome file.

## Valore restituito

Il valore True del nome del file è relativo.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
