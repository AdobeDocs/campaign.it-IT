# RegisterTransientSchema

Salva uno schema associato ai risultati di una query

```text
RegisterTransientSchema ( String name, String label, String sqltable, XML query )
```

## Parametri

Nome schema **name**

Etichetta schema **label**

**sqltable** Nome SQL della tabella

Definizione query **query**

## Valore/i restituito/i

Nessuno.
