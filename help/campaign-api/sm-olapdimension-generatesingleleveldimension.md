# GeneraDimensioneLivelloSingolo

Genera una dimensione a livello singolo basata su un campo.

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## Parametri

**dimension** Dimension da immettere

**campo** Campo o espressione utilizzati

## Valore/i restituito/i

**risultato** dimensione immessa
