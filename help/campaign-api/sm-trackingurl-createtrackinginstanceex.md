# CreateTrackingInstanceEx

Creare o configurare un’istanza di monitoraggio su un server di reindirizzamento

```text
CreateTrackingInstanceEx ( String internalPwd, String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword, String host, String imsOrgId )
```

## Parametri

**internalPwd** Password interna

**serverUrl** URL esterno del server di tracciamento

**secureServerUrl** URL protetto esterno del server di tracciamento

**serverUrlList** URL interni dei server di tracciamento

**instanceName** Nome dell&#39;istanza da creare

**password crittografata** password crittografata

**host** maschere DNS associate all&#39;istanza

**imsOrgId** ID organizzazione IMS

## Valore/i restituito/i

Nessuno.
