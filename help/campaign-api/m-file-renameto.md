# renameTo

Rinomina un file.

```text
renameTo (fileName)
```

## Parametri

**fileName** Nuovo nome file (deve essere un percorso completo).

## Valore restituito

Nessuno.

## Osservazioni

Esempi:

```javascript
var f = new File("c:/file.txt")
f.renameTo("c:/file2.txt")

var f2 = new File("c:/file.txt")
f2.renameTo("c:/dir/")
```
