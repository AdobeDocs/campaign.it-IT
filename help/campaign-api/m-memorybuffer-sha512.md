# sha512

Calcola la firma SHA-2 a 512 bit del contenuto MemoryBuffer.

```text
sha512 ()
```

## Parametri

Nessuno.

## Valore restituito

Stringa di caratteri che rappresenta esadecimalmente la firma SHA-2 a 512 bit.

## Funzioni

**Metodo di classe:** [MemoryBuffer](c-memorybuffer.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
