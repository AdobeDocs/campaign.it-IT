# createProcessingInstruction

Crea una nuova istruzione di elaborazione.

```text
createProcessingInstruction (target, data)
```

## Parametri

**target** Destinazione delle istruzioni di elaborazione, ad esempio &lt;?php ... ?>.

**dati** Stringa di caratteri da inserire nell&#39;istruzione.

## Valore restituito

[istruzione di elaborazione](c-domnode.md) creata.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
