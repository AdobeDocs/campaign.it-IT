# Enumerazione (classe)

Rappresenta la definizione di un&#39;enumerazione.

## Proprietà

| Proprietà | Descrizione |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Restituisce una stringa di caratteri che fornisce il tipo di enumerazione. |
| [predefinito](p-enumeration-default.md) | Restituisce una stringa di caratteri che fornisce il valore predefinito dell&#39;enumerazione. |
| [descrizione](p-enumeration-description.md) | Restituisce una stringa di caratteri che fornisce una descrizione dell&#39;enumerazione. |
| [hasImage](p-enumeration-hasimage.md) | Restituisce un valore booleano che indica se l’enumerazione dispone o meno di un’immagine. |
| [etichetta](p-enumeration-label.md) | Restituisce una stringa di caratteri che fornisce l&#39;etichetta dell&#39;enumerazione. |
| [nome](p-enumeration-name.md) | Restituisce una stringa di caratteri che fornisce il nome dell&#39;enumerazione. |
| [valori](p-enumeration-values.md) | Restituisce un oggetto per il quale ogni proprietà è un oggetto [EnumerationValue](c-enumerationvalue.md) indicizzato dal relativo valore. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
