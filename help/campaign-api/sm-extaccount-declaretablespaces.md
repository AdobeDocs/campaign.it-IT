# DichiaraSpaziTabella

Dichiara le opzioni, necessarie per utilizzare spazi di tabella specifici nel database remoto accessibile tramite l’account esterno, nel database di Adobe Campaign.

```text
DeclareTableSpaces ( String extAccountId, String tableSpace, String tableSpaceIndex )
```

## Parametri

**extAccountId** Nome interno o chiave primaria dell&#39;account esterno

**tableSpace** Nome della tablespace da utilizzare per le tabelle di lavoro remote

**tableSpaceIndex** Nome della tablespace da utilizzare per gli indici

## Valore/i restituito/i

Nessuno.

## Funzioni

**Schema:** [nms:extAccount](s-nms-extaccount.md)

**Statico:**

Sì
