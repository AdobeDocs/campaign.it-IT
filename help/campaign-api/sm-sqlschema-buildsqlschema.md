Genera il codice di uno schema a partire dalla struttura fisica della tabella specificata nei parametri.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Parametri

ID **dataSource** dell&#39;origine dati

**tableName** Nome tabella

## Valore/i restituito/i

**schema** generato dallo schema
