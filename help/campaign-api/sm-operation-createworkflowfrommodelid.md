# CreateWorkflowFromModelId

Crea un flusso di lavoro in una campagna in base a un modello di flusso di lavoro.

```text
Number workflowId = CreateWorkflowFromModelId ( Number modelId, XML operationPlanning )
```

## Parametri

**modelId** Identificatore modello flusso di lavoro

**operationPlanning** Pianificazione campagna

**workflowId** Identificatore dell&#39;istanza creata
