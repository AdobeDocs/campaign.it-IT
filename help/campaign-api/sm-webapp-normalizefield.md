# NormalizeField

```text
NormalizeField ( XML selectedWebApp, XML archivedField, String newSQLName, String tableName, String schemaId, Boolean rename )
```

## Parametri

**selectedWebApp** Elenco di sondaggi che possono contenere il campo da normalizzare.

**archivedField** Informazioni sul campo da normalizzare.

**newSQLName** Nuovo nome SQL di questo campo.

**tableName** Nome della tabella che conterrà il nuovo campo SQL.

**schemaId** Identificatore schema (visualizzazione) in cui aggiungere un riferimento appartenente al nuovo campo (facoltativo).

**rinomina** Rinomina anche i campi standardizzati in precedenza.

## Valore/i restituito/i

Nessuno.
