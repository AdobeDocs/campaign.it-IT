# Entità (classe)

Rappresenta un&#39;entità del database per uno schema specifico.

Non è possibile creare un&#39;istanza diretta di un oggetto di questo tipo. È necessario utilizzare i metodi create(), get() o load().

## Elemento “methods”

| Elemento “method” | Descrizione |
| --- | --- |
| [salva](m-entity-save.md) | Salva un&#39;entità nel database. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
