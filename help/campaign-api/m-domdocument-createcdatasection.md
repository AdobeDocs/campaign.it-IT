# createCDATASection

Crea un nuovo nodo di tipo CDATA.

```text
createCDATASection (data)
```

## Parametri

**dati** Stringa di caratteri da inserire nel nodo CDATA.

## Valore restituito

[Nodo CDATA](c-domcharacterdata.md) creato.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
