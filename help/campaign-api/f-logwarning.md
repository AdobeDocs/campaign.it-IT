# logWarning

Aggiunge un messaggio di avviso al registro dell&#39;istanza del flusso di lavoro.

```text
logWarning (message)
```

## Parametri

**message** Il messaggio da aggiungere al registro.

## Valore restituito

Nessuno.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
