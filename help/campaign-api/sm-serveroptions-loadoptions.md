# LoadOptions

> Avvertenza: questa funzione è disponibile per un ambiente locale.

Carica opzioni server

```text
XML result = LoadOptions ( XML select )
```

## Parametri

**select** Seleziona XPaths delle opzioni da caricare

## Valore/i restituito/i

**risultato** Aggiorna il documento delle opzioni
