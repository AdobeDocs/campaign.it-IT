# Protezione dei dati: funzioni di escape

Adobe Campaign fornisce una serie di funzioni che forniscono protezione contro gli attacchi più frequenti: SQL injection, XSS attack, ecc.

Le funzioni di escape devono essere utilizzate sotto la supervisione degli operatori e Adobe può non essere ritenuta responsabile dell’utilizzo scorretto o dell’assenza di utilizzo di tali funzioni durante gli sviluppi.

La regola generale è la seguente:

**Tutti i parametri devono essere preceduti da un carattere di escape. La funzione utilizzata per l&#39;escape dipende dal formato di destinazione dei dati.**

## escape semplificato

Nei JSSP, Adobe Campaign fornisce il tag &quot;&lt;%=&quot; che consente l’escape di una variabile utilizzata in un’entità XML o HTML generata. Questo metodo è più comodo ed è equivalente a NL.XML.escape(). L’esempio seguente illustra l’utilizzo del tag per eseguire l’escape di un parametro:

```xml
<li>
<%= strRecipientList %>
</li>
```

## Escape avanzato:

Adobe Campaign fornisce 4 funzioni che consentono di applicare l’escape a un parametro a seconda del formato di destinazione. Per accedere a queste funzioni di escape, assegna un nome ai file seguenti, rispettivamente:

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data) per applicare l&#39;escape a una variabile utilizzata in un&#39;entità XML o HTML generata. Questa funzione equivale alla sintassi &#39;&lt;%=&#39;. Questa funzione è definita nel pacchetto NL.XML.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) per eseguire l&#39;escape di un parametro che può essere utilizzato in una query SQL. Questa funzione inserisce automaticamente l’espressione tra virgolette semplici. Questa funzione è definita nel pacchetto NL.SQL.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) per eseguire l’escape di un parametro destinato a essere utilizzato in un’espressione XTK. Questa funzione è definita nel pacchetto NL.XTK.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data) per eseguire l’escape di una variabile utilizzata in javascript eseguita sul lato client. Questa funzione è definita nel pacchetto NL.JS.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

Avvertenza: Adobe Campaign non garantisce la durata di queste funzioni per le versioni successive.
