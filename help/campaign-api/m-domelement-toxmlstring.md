# toXMLString

Converte l&#39;elemento in una stringa di caratteri.

```text
toXMLString (format)
```

## Parametri

**format** Valore booleano per formattare il documento XML.

## Valore restituito

Nessuno.

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
