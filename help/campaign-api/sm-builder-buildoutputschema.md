# BuildOutputSchema

Genera uno schema da uno schema di origine.

```text
XML schema = BuildOutputSchema ( XML source, Boolean saveEntity )
```

## Parametri

Schema Source **source**

**saveEntity** Salva schema dopo la generazione

## Valore/i restituito/i

**schema** generato dallo schema
