# FillSteps

Crea automaticamente limitii per un numero uguale di raccoglitori.

```text
XML samplingSteps = FillSteps ( String schema, String expr, Number classCount )
```

## Parametri

**schema** Schema principale dell&#39;analisi

**expr** espressione Source

**classCount** numero di raccoglitori da generare

## Valore/i restituito/i

**samplingSteps** Elenco di passaggi

**Schema:** [xtk:abstractForm](s-xtk-abstractform.md)

Sì
