# fromHexString

Carica il contenuto di una stringa esadecimale nel buffer.

```text
fromHexString (string)
```

## Parametri

**stringa** Stringa di caratteri che rappresenta i dati binari codificati in formato esadecimale da aggiungere al buffer.

## Valore restituito

Nessuno.
