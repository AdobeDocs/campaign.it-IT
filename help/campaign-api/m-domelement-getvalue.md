# getValue

Restituisce il valore del nodo a cui fa riferimento l&#39;XPath specificato.

```text
getValue (xpath)
```

## Parametri

Percorso **xpath**.

## Valore restituito

Valore di testo del nodo a cui si fa riferimento.

## Osservazioni

La sintassi per XPath accetta solo un sottoinsieme di linguaggio XPath. Viene generata un&#39;eccezione se il percorso non è formattato correttamente.
