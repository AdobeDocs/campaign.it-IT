# BuildQueryEx

Restituisce la query generata e la stringa di formato

```text
[ String sql, String format ] = queryDef.BuildQueryEx () const
```

## Parametri

Nessuno.

## Valore/i restituito/i

**sql** query di output

**format** Stringa di formato, compatibile con la funzione JavaScript sqlSelect().

## Funzioni

**Schema:** [xtk:queryDef](s-xtk-querydef.md)

**Statico:**

No

**Costante:**

Sì

**Solo chiave:**

No
