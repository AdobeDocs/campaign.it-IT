# attributi

Restituisce una tabella contenente l’elenco degli attributi se il nodo è un elemento, altrimenti null.

```text
attributes
```

## Osservazioni

Questa proprietà crea una nuova tabella per ogni accesso. È quindi meglio mantenere la tabella in una variabile locale anziché accedere più volte alla proprietà.
