# DuplicaA

Duplica un nuovo documento da un documento di origine a una determinata cartella

```text
session.DuplicateTo ( String pk, String folder )
```

## Parametri

**pk** Chiave primaria del documento di origine

**cartella** Chiave primaria della cartella di destinazione

## Valore/i restituito/i

Nessuno.

## Funzioni

**Schema:** [xtk:session](s-xtk-session.md)

**Statico:**

No

**Costante:**

No

**Solo chiave:**

No
