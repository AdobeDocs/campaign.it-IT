# getRemoteAddress

Restituisce l’indirizzo IP del client o l’ultimo proxy ad aver inviato una richiesta.

```text
getRemoteAddr ()
```

## Parametri

Nessuno.

## Valore restituito

Stringa contenente l’indirizzo IP del client che ha inviato la query.

## Funzioni

**Metodo di classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponibile in:**

* JSSP
* WebApp
