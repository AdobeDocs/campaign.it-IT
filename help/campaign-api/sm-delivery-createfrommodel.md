# CreaDaModello

Creazione di una consegna da un modello (dal suo nome interno).

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## Parametri

**scenarioName** Nome interno del modello di consegna

**contenuto** contenuto XML da aggiungere al modello

## Valore/i restituito/i

**consegna** Restituisce il documento di consegna creato

## Funzioni

**Schema:** [nms:delivery](s-nms-delivery.md)

Sì
