# DumpInstanceStateEx

Stati restituiti dei processi server

```text
XML monitoring = DumpInstanceStateEx ( String mask, Boolean includeDead, Boolean noDatabaseCheck, Number criticalLevel )
```

## Parametri

**maschera** maschera per le istanze da considerare

**includeDead** Aggiungi elenco di processi inattivi

**noDatabaseCheck** non controlla gli avvisi dagli oggetti di database

**criticalLevel** filtra la gravità degli avvisi restituiti

## Valore/i restituito/i

**monitoraggio**
