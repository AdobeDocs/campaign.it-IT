# salva

Salva l&#39;archivio.

```text
save ( [filename ] [, overwrite ])
```

## Parametri

**nomefile** Nome dell&#39;archivio. Se il nome non è specificato o è vuoto, l&#39;archivio viene salvato con il nome originale.

**sovrascrivi** Se &#39;false&#39;, l&#39;archivio non verrà salvato se esiste già un file con questo nome e verrà generata un&#39;eccezione.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [ZipFile](c-zipfile.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
