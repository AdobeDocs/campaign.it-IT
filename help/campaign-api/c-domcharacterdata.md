# DOMCharacterData (classe)

Nodo contenente solo testo. Può essere un nodo di tipo testo o un commento.

## Elemento “methods”

| Elemento “method” | Descrizione |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | Estrarre una parte del testo. |
| [appendData](m-domcharacterdata-appenddata.md) | Aggiungi una stringa di caratteri al testo. |
| [inserisciDati](m-domcharacterdata-insertdata.md) | Inserisce una stringa di caratteri nel testo in una posizione specifica. |
| [deleteData](m-domcharacterdata-deletedata.md) | Elimina una parte del testo. |
| [replaceData](m-domcharacterdata-replacedata.md) | Sostituire una parte del testo. |

## Proprietà

| Proprietà | Descrizione |
