# DispatchImages

Indica al server dell’applicazione di inviare le immagini al server mid-sourcing.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Parametri

**immagini** Elenco di immagini da caricare sul server di mid-sourcing.

**providerId** Identificatore del router di consegna.

**providerName** Nome del router di consegna.

## Valore/i restituito/i

Nessuno.

Sì
