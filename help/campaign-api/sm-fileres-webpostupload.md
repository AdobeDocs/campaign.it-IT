# WebPostUpload

Completa l’archiviazione della risorsa dopo il caricamento (da una pagina web) sul server, a seconda del tipo di archiviazione utilizzata. Recupera la tabella codici e il tipo di contenuto.

```text
fileRes.WebPostUpload ( XML params )
```

## Parametri

**params** Per l&#39;archiviazione di tipo &#39;workspace&#39;: @formerFileName contiene il nome precedente nell&#39;area di lavoro. Se desideri salvare l’entità immediatamente: @immediateSave deve essere impostato su &quot;true&quot;

## Valore/i restituito/i

Nessuno.

No

No
