# GetSource

Codice sorgente per la gestione dei moduli.

```text
[ String source, XML logs ] = GetSource ( String formId, String target, Boolean compiled, String version )
```

## Parametri

**formId** Identificatore modulo.

Tipo di documento **target** da generare.

**compilato** Recupera la versione completa

**versione** versione del documento da generare.

## Valore/i restituito/i

**codice sorgente** Source.

**logs** Generation logs.
