# DeployTriggerMessages

Pubblica i messaggi transazionali selezionati sulle istanze di esecuzione

```text
DeployTriggerMessages ( XML deliveries, Boolean localPublish )
```

## Parametri

**consegne** Filtra le condizioni per definire i messaggi transazionali da distribuire

**localPublish** Pubblicare solo sull&#39;istanza di controllo?

## Valore/i restituito/i

Nessuno.

## Funzioni

**Schema:** [nms:delivery](s-nms-delivery.md)

**Statico:**

Sì
