# transizioni

Restituisce l’elenco delle transizioni dell’attività.

```text
transitions ()
```

## Parametri

Nessuno.

## Valore restituito

Una tabella contenente tutte le transizioni dell’attività nell’ordine in cui sono definite.

## Funzioni

**Metodo di classe:** [WorkflowTask](c-workflowtask.md)

**Disponibile in:**

* Flusso di lavoro
