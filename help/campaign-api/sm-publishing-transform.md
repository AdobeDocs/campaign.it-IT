# Trasforma

Pubblicazione della trasformazione da un contenuto

```text
[ String format, String result ] = Transform ( String publishingId, String modelName, XML content )
```

## Parametri

**publishingId** Identificatore del modello di pubblicazione

**modelName** Nome del modello di trasformazione

**contenuto** Dati contenuto da trasformare

## Valore/i restituito/i

**format** Formato di output

**risultato** risultato della trasformazione
