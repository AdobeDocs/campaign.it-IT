# transitionByType

Restituisce la transizione corrispondente al tipo specificato.

```text
transitionByType (type)
```

## Parametri

**tipo** Tipo di transizione.

## Valore restituito

La prima transizione per cui il tipo viene passato come parametro; in caso contrario, viene restituito null se l’attività non ha una transizione di questo tipo.

## Funzioni

**Metodo di classe:** [WorkflowTask](c-workflowtask.md)

**Disponibile in:**

* Flusso di lavoro
