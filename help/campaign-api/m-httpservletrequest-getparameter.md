# getParameter

Restituisce il valore di un parametro di query.

```text
getParameter (name)
```

## Parametri

**name** Nome parametro.

## Valore restituito

Il valore del parametro richiesto.

## Funzioni

**Metodo di classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponibile in:**

* JSSP
* WebApp
