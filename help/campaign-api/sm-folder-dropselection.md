# DropSelection

Spostare la selezione in una cartella della struttura di navigazione

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## Parametri

**schema** ID schema selezione

ID **entityFolder** della cartella di destinazione

**selectionList** Selezione da spostare

**folderDestId** Cartella di destinazione

## Valore/i restituito/i

Nessuno.

## Funzioni

**Schema:** [xtk:folder](s-xtk-folder.md)

**Statico:**

Sì
