# GenerateLinkDimension

Genera una dimensione basata su un collegamento.

```text
XML result = GenerateLinkDimension ( XML dimension, XML linklevels )
```

## Parametri

**dimension** Dimension da immettere

**linklevels** Livelli disponibili

## Valore/i restituito/i

**risultato** dimensione immessa
