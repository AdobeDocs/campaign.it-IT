# CalculateNextReminderDate

Calcola la data del promemoria successivo (vuoto = nessuna).

```text
Date parentOut = CalculateNextReminderDate ( Date lastReminderDate, Date expectedDate, XML parameter )
```

## Parametri

**lastReminderDate** Ultima data promemoria utilizzata

**expectedDate** data di approvazione

Configurazione **parametro**

## Valore/i restituito/i

Risultato **parentOut**
