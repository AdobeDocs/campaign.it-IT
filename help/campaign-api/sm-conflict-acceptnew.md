# AcceptNew

Accetta la nuova versione come versione corrente.

```text
AcceptNew ( String conflictId )
```

## Parametri

**conflittoId** Identificatore di conflitto.

## Valore/i restituito/i

Nessuno.

## Osservazioni

Il conflitto viene eliminato dal database.
