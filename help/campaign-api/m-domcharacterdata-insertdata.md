# insertData

Inserisce una stringa di caratteri nel testo in una posizione specifica.

```text
insertData (offset, arg)
```

## Parametri

**offset** Posizione di inserimento (0 per il primo carattere).

**arg** Stringa di caratteri da inserire.

## Valore restituito

Nessuno.
