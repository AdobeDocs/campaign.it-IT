# RegisterTrackingInstance

Approva un’istanza di tracciamento su un server di reindirizzamento (impostando l’identificatore di database).

```text
RegisterTrackingInstance ( String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword )
```

## Parametri

**serverUrl** URL esterno del server di tracciamento

**secureServerUrl** URL protetto esterno del server di tracciamento

**serverUrlList** URL interni dei server di tracciamento

**instanceName** Nome dell&#39;istanza da approvare

**password crittografata** password crittografata

## Valore/i restituito/i

Nessuno.

**Schema:** [nms:trackingUrl](s-nms-trackingurl.md)

**Statico:**

Sì
