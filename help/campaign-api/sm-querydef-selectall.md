# SelectAll

Aggiunge tutti i campi nella parte di selezione.

```text
queryDef.SelectAll ( Boolean duplicate )
```

## Parametri

**duplicate** Specifica se si sta eseguendo la duplicazione, nel qual caso aggiunge tutti gli elementi OwnCopy.

## Valore/i restituito/i

Nessuno.

No

No

No
