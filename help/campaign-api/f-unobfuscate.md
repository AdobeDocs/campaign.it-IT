# unobfuscate

Rimuove il numero intero precedentemente offuscato grazie a [obfuscate](f-obfuscate.md).

```text
unobfuscate (value [, version ])
```

## Parametri

**value** Numero intero da oscurare.

**versione** versione di unobfuscation da applicare. 0 per impostazione predefinita.

## Valore restituito

Numero intero precedentemente offuscato da [obfuscate](f-obfuscate.md).

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
