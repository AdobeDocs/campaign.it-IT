# TransformXSLT

Trasformazione della pubblicazione basata su XSLT

```text
String result = TransformXSLT ( String source, String namespace, String format, String contentId )
```

## Parametri

**sorgente** contenuto foglio di stile XSLT

**spazio dei nomi** utilizzato per le direttive xsl:import relative

**format** Formato di output

**contentId** Identificatore contenuto

## Valore/i restituito/i

**risultato** risultato della trasformazione
