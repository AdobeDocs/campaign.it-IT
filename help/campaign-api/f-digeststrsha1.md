# digestStrSha1

> Avvertenza:
>
> Questa funzione non deve essere utilizzata per creare hash basati su Informazioni personali.

Calcola l’hash SHA-1 di una stringa di caratteri. La stringa viene codificata automaticamente in UTF-8 prima del calcolo.

```text
digestStrSha1 (string)
```

## Parametri

**stringa** Stringa in cui deve essere calcolato l&#39;hash.

## Valore restituito

Hash SHA-1 della stringa passata come parametro.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
