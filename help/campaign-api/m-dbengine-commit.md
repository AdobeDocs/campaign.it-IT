# commit

Approva la transazione in corso sulla connessione.

```text
commit ()
```

## Parametri

Nessuno.

## Valore restituito

Nessuno.

## Osservazioni

Una transazione deve essere stata iniziata in precedenza utilizzando il metodo [begin](m-dbengine-begin.md).

## Funzioni

**Metodo di classe:** [DBEngine](c-dbengine.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
