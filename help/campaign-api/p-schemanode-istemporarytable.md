# isTemporaryTable

Restituisce un valore booleano che indica se la tabella è temporanea. La tabella non verrà creata durante la creazione del database.

```text
isTemporaryTable
```

## Funzioni

**Proprietà della classe:** [SchemaNode](c-schemanode.md)

**Sola lettura:**

Sì
