# CreateInstanceEx

Utilizzato per creare un’istanza di tracciamento

```text
CreateInstanceEx ( String instanceName, String hosts, String dbId, String cryptedPwd, String lang, String imsOrgId )
```

## Parametri

**instanceName** Nome dell&#39;istanza da creare

**host** maschere DNS associate all&#39;istanza

**dbId** Identificatore di database per il cliente che esegue una consegna

**cryptedPwd** Password crittografata utilizzata per il tracciamento

**lang** Lingua istanza

**imsOrgId** ID organizzazione IMS

Nessuno.
