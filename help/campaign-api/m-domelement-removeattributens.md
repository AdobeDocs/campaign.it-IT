# removeAttributeNS

Eliminare un attributo.

```text
removeAttributeNS (namespaceURI, localName)
```

## Parametri

**namespaceURI** URI dell&#39;attributo namespace.

Nome attributo **localName**.

## Valore restituito

Nessuno.

## Osservazioni

Il metodo non ha alcun effetto se l&#39;elemento non ha un attributo con questo nome.
