# hasAttributeNS

Verificare l&#39;esistenza di un attributo.

```text
hasAttributeNS (namespaceURI, localName)
```

## Parametri

**namespaceURI** URI dell&#39;attributo namespace.

Nome attributo **localName**.

## Valore restituito

true se l&#39;attributo esiste, altrimenti false.
