# GetNewIdsEx

Ottieni un elenco di identificatori univoci dal database, con un nome di sequenza.

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Parametri

**count** Numero di identificatori che questo metodo deve restituire

**sequenza** Nome della sequenza da incrementare

## Valore/i restituito/i

**idList** elenco di identificatori separati da virgole
