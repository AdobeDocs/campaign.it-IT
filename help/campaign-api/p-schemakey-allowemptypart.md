# allowEmptyPart

Restituisce true se i campi della chiave possono essere vuoti (è necessario immettere almeno uno dei campi).

```text
allowEmptyPart
```

**Proprietà della classe:** [SchemaKey](c-schemakey.md)

**Sola lettura:**

Sì
