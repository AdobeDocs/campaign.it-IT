# childNodes

Restituisce l&#39;elenco dei nodi figlio sotto forma di tabella.

```text
childNodes
```

## Osservazioni

Questa proprietà crea una nuova tabella per ogni accesso. Pertanto, è meglio mantenere la tabella in una variabile locale anziché eseguire più volte l’operazione di query sulla proprietà.
