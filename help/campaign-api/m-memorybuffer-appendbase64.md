# appendBase64

Aggiunge i dati di una stringa di caratteri codificata in base 64 alla fine del buffer.

```text
appendBase64 (string)
```

## Parametri

**stringa** Stringa di caratteri che rappresenta i dati binari codificati in base 64 da aggiungere al buffer.

## Valore restituito

Nessuno.
