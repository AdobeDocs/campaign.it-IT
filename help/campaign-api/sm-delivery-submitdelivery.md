# SubmitDelivery

Creazione e invio di una consegna da uno scenario (dal relativo nome interno).

```text
Number deliveryId = SubmitDelivery ( String scenarioName, XML content )
```

## Parametri

**scenarioName** Nome interno del modello di consegna

**contenuto** contenuto XML da aggiungere al modello

## Valore/i restituito/i

**deliveryId** Identificatore della nuova consegna (restituito anche se l&#39;analisi non riesce)
