# setAttribute

Modificare il valore di un attributo o crearne uno nuovo.

```text
setAttribute (name, value)
```

## Parametri

Nome attributo **name**.

**value** Valore di testo attributo.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [DOMElement](c-domelement.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
