# Utilizzo di XML

Molte API di JavaScript accettano gli oggetti di tipo XML come parametri o li restituiscono. Le versioni precedenti di Adobe Campaign utilizzavano l’estensione JavaScript E4X per questo scopo, che consentiva di manipolare direttamente gli elementi XML nel linguaggio. Tuttavia, questa tecnologia viene lentamente abbandonata.

Per sostituire questa tecnologia, sono stati aggiunti nuovi oggetti per manipolare i documenti XML. Riprendono un sottoinsieme dell&#39;interfaccia DOM (Document Object Model) con alcune estensioni. Un oggetto notazione è disponibile anche per creare facilmente documenti XML, è una versione semplificata della convenzione JXON BadgetFish.

## Interfaccia DOM

Un oggetto [DOMDocument](c-domdocument.md) è un documento XML. Può essere creata da una stringa di caratteri, un oggetto JXON o direttamente da un file. Di seguito è riportato un esempio di creazione di un documento DOM:

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

Questa interfaccia fa parte della specifica W3C con varie differenze notevoli:

* Le funzioni getElements\* e le proprietà childNodes e attributes restituiscono una tabella JavaScript anziché un oggetto NodeList, consentendo l&#39;utilizzo delle funzioni proprie delle tabelle: forEach, map, ...
* Alcune proprietà restituiscono una stringa vuota anziché un valore null quando il valore non è stato specificato.

Sono state inoltre aggiunte alcune funzioni di utilità e alcune estensioni non standard. Ad esempio, per leggere o modificare un attributo, è necessario solo scrivere:

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

anziché:

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

L&#39;assegnazione di un attributo con la proprietà $name può richiedere una stringa, un valore booleano, una data o un numero. Il valore verrà automaticamente convertito in una stringa di caratteri:

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON è una convenzione di notazione per gli oggetti JavaScript per creare facilmente documenti XML. Questa notazione non consente di creare tutti i documenti XML possibili. Ad esempio, non consente di specificare un elemento con lo stesso nome di un attributo e gli spazi dei nomi non vengono gestiti. È adatto per i documenti di Adobe Campaign. Per esigenze più complesse, puoi sempre utilizzare le funzioni DOM tradizionali (analisi o creazione elemento per elemento). L&#39;oggetto XML è rappresentato da un oggetto JavaScript le cui proprietà corrispondono agli elementi e agli attributi. Il tipo di valore determina se ha a che fare con un elemento o un attributo.

* Stringa Un attributo il cui valore è la stringa di caratteri
* Booleano Attributo il cui valore è &#39;true&#39; o &#39;false&#39;
* Numero Attributo il cui valore è la rappresentazione del numero decimale
* Data Attributo il cui valore è la rappresentazione ISO-8601 della data e dell&#39;ora
* Oggetto Un elemento
* Array Elenco di elementi

Per il contenuto di testo di un elemento viene utilizzata una proprietà speciale con il nome $. Esempi:

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

Se le proprietà contengono caratteri speciali che non sono identificatori JavaScript validi, è necessario racchiuderli tra virgolette.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

Gli oggetti JXON possono essere utilizzati in argomenti ovunque una funzione preveda un documento o un elemento XML. Ad esempio:

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

equivale a:

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

È importante notare che la manipolazione dei documenti XML viene eseguita da oggetti DOM; gli oggetti JXON sono utility utilizzate solo per l&#39;inizializzazione. È più utile creare un documento XML da una struttura JavaScript letterale, in particolare quando il documento contiene parti variabili.
