# Separatore

Visualizzare un separatore con un testo e un&#39;immagine.

![Controllo separatore](assets/separator.70317a27.png)

## Proprietà

**direction - stringa** Horizontal per impostazione predefinita.

**img - stringa** immagine associata.

**etichetta - stringa** Testo da visualizzare.

## Osservazioni

Esempio:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
