# fromString

Carica il contenuto di una stringa di caratteri nel buffer.

```text
fromString (string [, codepage ])
```

## Parametri

**stringa** Stringa di caratteri.

**tabella codici** Tabella codici utilizzata per serializzare la stringa nel buffer. Questo parametro opzionale consente di specificare la codifica dei caratteri. Ad esempio:

* iso-8859-1
* utf-8
* utf-16
* us-ascii
* shift-jis
* euc-kr

## Valore restituito

Nessuno.

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
