# appendChild

Inserisci un nodo alla fine dell’elenco delle sottocartelle.

```text
appendChild (newChild)
```

## Parametri

**newChild** nodo da inserire.

## Valore restituito

Nodo inserito.

## Funzioni

**Metodo di classe:** [DOMNode](c-domnode.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
