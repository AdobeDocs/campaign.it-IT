# getFirstElement

Restituisce il primo elemento figlio verificando i criteri specificati.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Parametri

**tagName** Nome dell&#39;elemento cercato.

**attrName** Nome di un attributo che deve verificare un determinato valore.

Valore attributo **attrValue**.

## Valore restituito

Primo elemento che verifica il criterio specificato o null.
