# ExecuteTransientQuery

Esegue una query e memorizza il risultato in una tabella di lavoro

```text
ExecuteTransientQuery ( String name, String label, String sqltable, XML query )
```

## Parametri

Nome schema **name**

Etichetta schema **label**

**sqltable** Nome SQL della tabella

Definizione query **query**

## Valore/i restituito/i

Nessuno.
