# LoadChildren

Carica elenco degli elementi secondari per un dato nodo

```text
XML result = LoadChildren ( String parentKey, String folderFilter, Boolean writeAccess, String fullName, Boolean sort )
```

## Parametri

**parentKey** chiave padre

**folderFilter** filtra le cartelle

**writeAccess** La cartella restituita deve essere scrivibile

**fullName** Nome completo del nodo selezionato

**ordina** Ordina per ordine alfabetico

## Valore/i restituito/i

**risultato** documento dei risultati

**Schema:** [xtk:folder](s-xtk-folder.md)

Sì
