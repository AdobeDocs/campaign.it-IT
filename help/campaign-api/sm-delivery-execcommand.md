# ExecCommand

Esegue un comando su una consegna.

```text
Number newState = ExecCommand ( String deliveryId, String command )
```

## Parametri

**deliveryId** Identificatore di consegna

**comando** Nome comando (&#39;play&#39;, &#39;pause&#39; o &#39;stop&#39;)

## Valore/i restituito/i

**newState** Stato della consegna dopo l&#39;esecuzione del comando
