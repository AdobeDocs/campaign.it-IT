# digestStrMd5

> Avvertenza:
>
> Questa funzione non deve essere utilizzata per creare hash basati su Informazioni personali.

Calcola la funzione hash MD5 per una stringa di caratteri. La stringa viene codificata automaticamente in UTF-8 prima del calcolo.

```text
digestStrMd5 (string)
```

## Parametri

**stringa** Stringa per la quale calcolare la funzione hash.

## Valore restituito

Hash MD5 della stringa passata come parametro.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
