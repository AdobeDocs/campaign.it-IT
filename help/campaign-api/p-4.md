# Eccezioni JavaScript

Per impostazione predefinita, quando si verifica un errore, lo script in esecuzione viene interrotto. A partire dalla versione 4.05, tuttavia, è possibile acquisire gli errori e gestirli per continuare l&#39;elaborazione dello script.

Le eccezioni generate da Adobe Campaign sono codici di errore ( tipo `Number`).

## Esempio

Questo esempio tenta di recuperare una pagina Web da un indirizzo non valido e genera un&#39;eccezione dalla funzione [getUrl()](f-geturl.md).

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
