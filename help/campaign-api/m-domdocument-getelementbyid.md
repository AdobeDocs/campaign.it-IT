# getElementById

Restituisce l&#39;elemento con l&#39;ID specificato.

```text
getElementById (elementId)
```

## Parametri

**elementId** Identificatore dell&#39;elemento cercato. Una stringa di caratteri con sensibilità significativa alle maiuscole/minuscole.

## Valore restituito

Elemento o null se il documento non contiene alcun elemento con un ID specifico.

**Metodo di classe:** [DOMDocument](c-domdocument.md)
