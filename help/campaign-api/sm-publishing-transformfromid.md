# TransformFromId

Pubblicazione della trasformazione da un ID contenuto

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Parametri

**publishingId** Identificatore del modello di pubblicazione

**modelName** Nome del modello di trasformazione

**contentId** Identificatore contenuto

## Valore/i restituito/i

**format** Formato di output

**risultato** risultato della trasformazione
