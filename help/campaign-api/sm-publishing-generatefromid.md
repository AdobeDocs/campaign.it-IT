# GenerateFromId

Genera e pubblica il contenuto a cui fa riferimento un identificatore in una cartella

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## Parametri

Identificatore del contenuto **id**

**publishingDir** Cartella di pubblicazione

## Valore/i restituito/i

**outputFiles** Elenco dei file generati
