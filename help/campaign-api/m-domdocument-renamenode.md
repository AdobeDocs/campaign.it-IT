# renameNode

Modifica il nome di un elemento o di un attributo.

```text
renameNode (node, namespaceURI, qualifiedName)
```

## Parametri

**nodo** nodo di tipo elemento/attributo.

**namespaceURI** Nuovo URI dello spazio dei nomi.

**qualificatoName** Nuovo nome qualificato.

## Valore restituito

Nodo rinominato. Può trattarsi del nodo specificato o di un nodo che sostituisce quello precedente.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
