# digestStrSha512

Calcola l’hash SHA-512 di una stringa di caratteri. La stringa viene codificata automaticamente in UTF-8 prima del calcolo.

```text
digestStrSha512 (string)
```

## Parametri

**stringa** Stringa in cui deve essere calcolato l&#39;hash.

## Valore restituito

Hash SHA-512 della stringa passato come parametro.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
