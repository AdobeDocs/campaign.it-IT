# sendRedirect

Restituisce un reindirizzamento temporaneo a un altro URL.

```text
sendRedirect (location)
```

## Parametri

URL di reindirizzamento **location**.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponibile in:**

* JSSP
* WebApp
