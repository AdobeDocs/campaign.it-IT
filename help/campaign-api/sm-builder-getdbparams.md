# GetDbParams

Recupera i parametri correnti dell’origine dati.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## Parametri

Nessuno.

## Valore/i restituito/i

**dbcnx** Definizione origine dati

**dbParameters** Aggiorna gli spazi dei nomi e le tablespace.
