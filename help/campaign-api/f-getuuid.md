# getUUID

Generazione di un identificatore univoco (ID universalmente univoco).

```text
getUUID ()
```

## Parametri

Nessuno.

## Valore restituito

Stringa di caratteri che contiene un ID univoco del tipo &#39;550E8400-E29B-41D4-A716-446655440000&#39;.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
