# toXMLString

Converte il documento XML in una stringa di caratteri.

```text
toXMLString (format)
```

## Parametri

**format** Valore booleano per formattare il documento XML.

## Valore restituito

Nessuno.

## Osservazioni

Questo metodo aggiunge il prologo, a differenza del metodo con lo stesso nome sugli elementi.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
