# createElementNS

Crea un nuovo elemento con il nome e lo spazio dei nomi specificati.

```text
createElementNS (namespaceURI, qualifiedName)
```

## Parametri

**namespaceURI** URI dello spazio dei nomi.

**qualificatoName** Nome qualificato dell&#39;elemento da creare.

## Valore restituito

[elemento](c-domelement.md) creato.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
