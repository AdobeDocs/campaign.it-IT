# fileRinomina

Modifica il nome di un file.

Se la codifica dei caratteri non è specificata, viene utilizzato il server predefinito.

```text
fileRename (oldname, newname)
```

## Parametri

**oldname** Nome completo del file da rinominare.

**newname** Il nuovo nome del file.

## Valore restituito

Nessuno.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
