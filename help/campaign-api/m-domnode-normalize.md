# normalizzare

Normalizza il nodo: i nodi di testo adiacenti vengono uniti e i nodi di testo vuoti vengono eliminati.

```text
normalize ()
```

## Parametri

Nessuno.

## Valore restituito

Nessuno.

* Messaggio di consegna

* Importazione

* Metodo SOAP
