# hasElement

Verifica se l’elemento ha un elemento figlio verificando i criteri specificati.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Parametri

**tagName** Nome dell&#39;elemento cercato.

**attrName** Nome di un attributo che deve verificare un determinato valore.

Valore attributo **attrValue**.

## Valore restituito

true se l’elemento ha un elemento figlio verificando i dati forniti, altrimenti false.
