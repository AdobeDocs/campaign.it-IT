# isDefaultOnDuplicate

Restituisce un valore booleano. Se il valore aggiunto è variabile, durante la deduplicazione dei record il valore predefinito (definito in defaultValue) viene riapplicato automaticamente durante la registrazione.

```text
isDefaultOnDuplicate
```
