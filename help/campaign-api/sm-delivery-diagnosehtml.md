# DiagnoseHTML

Avvia la diagnostica dei contenuti HTML

```text
XML diagnostic = DiagnoseHTML ( String htmlContent, Number format )
```

## Parametri

**htmlContent** contenuto HTML da controllare

**formato** Il formato di posta

## Valore/i restituito/i

**diagnostic** Restituisce la diagnostica
