# isDefaultNamespace

Verifica se lo spazio dei nomi specificato è quello predefinito.

```text
isDefaultNamespace (namespaceURI)
```

## Parametri

**namespaceURI** URI dello spazio dei nomi.

## Valore restituito

true se namespaceURI è lo spazio dei nomi predefinito, altrimenti false.
