# transitionByName

Restituisce le transizioni corrispondenti al nome specificato.

```text
transitionByName (name)
```

## Parametri

**nome** Nome della transizione.

## Valore restituito

La transizione con il nome passato come parametro, altrimenti null se l’attività non ha una transizione con questo nome.

## Funzioni

**Metodo di classe:** [WorkflowTask](c-workflowtask.md)

**Disponibile in:**

* Flusso di lavoro
