# CreateFromCatalog

Crea un ordine da un pacchetto.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## Parametri

**catalogId** ID pacchetto.

**orgUnitId** ID entità locale. (facoltativo)

## Valore/i restituito/i

**localOrder** Restituisce l&#39;ordine creato.
