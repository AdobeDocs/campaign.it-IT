# SchemaKey (classe)

Rappresenta la definizione di una chiave.

## Proprietà

| Proprietà | Descrizione |
| --- | --- |
| [etichetta](p-schemakey-label.md) | Restituisce la breve descrizione della chiave. |
| [descrizione](p-schemakey-description.md) | Restituisce la descrizione della chiave. |
| [nome](p-schemakey-name.md) | Restituisce l’identificatore della chiave. |
| [isInternal](p-schemakey-isinternal.md) | Restituisce true se la chiave è la chiave interna. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | Restituisce true se i campi della chiave possono essere vuoti (è necessario immettere almeno uno dei campi). |
| [campi](p-schemakey-fields.md) | Restituisce una tabella contenente il campo dei campi ( [SchemaNode](c-schemanode.md) ) della chiave. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
