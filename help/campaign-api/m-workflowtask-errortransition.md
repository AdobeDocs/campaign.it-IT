# errorTransition

Restituisce la transizione &quot;error&quot; dell’attività.

```text
errorTransition ()
```

## Parametri

Nessuno.

## Valore restituito

La prima attività &quot;completata&quot;, se trovata, altrimenti null.

## Funzioni

**Metodo di classe:** [WorkflowTask](c-workflowtask.md)

**Disponibile in:**

* Flusso di lavoro
