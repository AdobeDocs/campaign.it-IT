# CollectLogs

Crea una tabella con tutti i messaggi del registro di consegna per un elenco di consegne

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## Parametri

Identificatore univoco per assegnazione priorità **id**

**consegne** elenco di consegne da considerare

**logTable** tabella da creare per contenere tutti i messaggi di registro

## Valore/i restituito/i

Nessuno.
