# logVerbose

Aggiunge un messaggio informativo al registro dell’istanza del flusso di lavoro. Questo messaggio è visibile solo in modalità dettagliata.

```text
logVerbose (message)
```

## Parametri

**message** Il messaggio da aggiungere al registro.

## Valore restituito

Nessuno.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
