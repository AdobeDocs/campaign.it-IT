# hasAttribute

Verificare l&#39;esistenza di un attributo.

```text
hasAttribute (name)
```

## Parametri

Nome attributo **name**.

## Valore restituito

true se l&#39;attributo esiste, altrimenti false.

* Proprietà di consegna

* Flusso di lavoro
