# Pagina direttiva

Include una libreria di funzioni o stringhe.

## Sintassi

&lt;%@ page import=&quot;lib1, ...&quot; %> &lt;%@ page stringGroup=&quot;groupName&quot; %>

## Descrizione

L&#39;importazione di una libreria di stringhe espone un oggetto JavaScript globale il cui nome inizia con sg\_ seguito dal nome della libreria i cui caratteri speciali sono stati sostituiti con &quot;\_&quot;. Ad esempio, l&#39;inclusione di nms:campaign creerà la variabile sg\_nms\_campaign.

## Esempio

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
