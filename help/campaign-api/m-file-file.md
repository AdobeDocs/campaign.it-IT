# File

Crea un nuovo oggetto associato a un file.

```text
File (filename)
```

## Parametri

**nomefile** Nome del file da leggere o creare.

## Valore restituito

Nessuno.

## Osservazioni

Esempio:

```javascript
var f = new File("/tmp/file.txt")
```
