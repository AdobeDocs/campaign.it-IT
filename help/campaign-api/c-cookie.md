# Cookie (classe)

Rappresenta un cookie scambiato dal servlet e dal browser Web.

## Proprietà

| Proprietà | Descrizione |
| --- | --- |
| [nome](p-cookie-name.md) | Nome del cookie. |
| [commento](p-cookie-comment.md) | Commento che descrive la funzione del cookie, null se non definito. |
| [dominio](p-cookie-domain.md) | Nome di dominio del cookie. |
| [maxAge](p-cookie-maxage.md) | Durata dei cookie in secondi. |
| [percorso](p-cookie-path.md) | Percorso in base al quale il browser web inoltra il cookie. |
| [protetto](p-cookie-secure.md) | true se il cookie può essere inoltrato solo tramite un protocollo sicuro. |
| [valore](p-cookie-value.md) | Valore cookie. |
| [versione](p-cookie-version.md) | Versione del protocollo compatibile con il cookie. |

## Funzioni

**Disponibile in:**

* JSSP
* WebApp
