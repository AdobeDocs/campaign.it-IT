# PushEvents

Inserisci una raccolta di eventi.

```text
XML ids = PushEvents ( XML eventCollection )
```

## Parametri

**raccolta eventi** Raccolta di eventi.

## Valore/i restituito/i

Raccolta **ids** contenente la combinazione degli identificatori esterni e interni utilizzati durante l&#39;inserimento.
