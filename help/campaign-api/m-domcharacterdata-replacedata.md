# replaceData

Sostituire una parte del testo.

```text
replaceData (offset, count, arg)
```

## Parametri

**offset** Posizione del primo carattere da eliminare (0 per il primo carattere).

**count** Numero di caratteri da eliminare.

**arg** Stringa di caratteri da inserire.

## Valore restituito

Nessuno.
