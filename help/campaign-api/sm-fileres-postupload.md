# PostUpload

Elaborazione post-caricamento a seconda del tipo di archiviazione definito.

```text
fileRes.PostUpload ( XML params )
```

## Parametri

**params** Per l&#39;archiviazione di tipo &#39;workspace&#39;: @formerFileName contiene il nome precedente nell&#39;area di lavoro. Se desideri salvare l’entità immediatamente: @immediateSave deve essere impostato su &quot;true&quot;

Nessuno.
