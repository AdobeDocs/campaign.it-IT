# RecomputeStats

Ricalcola le statistiche di consegna e tracciamento di un’azione di consegna.

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## Parametri

**deliveryId** Identificatore di consegna

**dirtyFlags** Campo di bit che descrive gli elementi da ricalcolare (vedere l&#39;enumerazione &#39;nms:delivery:dirtyFlags&#39;).

## Valore/i restituito/i

Nessuno.

**Schema:** [nms:delivery](s-nms-delivery.md)

**Statico:**

Sì
