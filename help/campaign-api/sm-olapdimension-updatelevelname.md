# UpdateLevelName

Aggiorna il nome interno di un livello in base alla sua espressione.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Parametri

**livello** Livello da modificare

**dimensione** Dimensione principale del livello

## Valore/i restituito/i

**risultato** Livello modificato

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)
