# toDocument

Converte lo schema in un modulo di documento XML.

```text
toDocument ()
```

## Parametri

Nessuno.

## Valore restituito

Oggetto di tipo [DOMDocument](c-domdocument.md).

## Funzioni

**Metodo di classe:** [Schema](c-schema.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
