# postEvent

Attiva una transizione.

```text
postEvent (transition)
```

## Parametri

**transizione** La transizione da attivare.

## Valore restituito

Nessuno.

## Osservazioni

L’attività target della transizione viene attivata e riceve le variabili dell’attività.

## Funzioni

**Metodo di classe:** [WorkflowTask](c-workflowtask.md)

**Disponibile in:**

* Flusso di lavoro
