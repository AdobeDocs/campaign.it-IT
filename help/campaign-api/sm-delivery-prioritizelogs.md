# PrioritizeLogs

Assegna la priorità al registro di consegna per un elenco di consegne

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Parametri

Identificatore univoco per assegnazione priorità **id**

**consegne** elenco di consegne da considerare

**logTable** tabella contenente tutti i messaggi di log

## Valore/i restituito/i

Nessuno.
