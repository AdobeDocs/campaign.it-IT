# RecipientSubscribe

Destinatari che hanno selezionato di iscriversi/annullare l’iscrizione a un elenco di Servizi di informazione.

```text
XML confirmationIds = RecipientSubscribe ( XML recipientList, XML serviceList, Boolean subscribe, XML sendConfirmation )
```

## Parametri

**elenco destinatari** elenco destinatari

**serviceList** Elenco dei servizi

**abbonati** Destinatari abbonati/annullati abbonamento

**sendConfirmation** Invia un messaggio di conferma

## Valore/i restituito/i

**confirmIds** Elenco di ID di conferma

## Funzioni

**Schema:** [nms:subscription](s-nms-subscription.md)

**Statico:**

Sì
