# Esempi

## Metodi statici

Per accedere ai metodi di SOAP, si richiama un metodo sull’oggetto che rappresenta lo schema. Gli schemi sono oggetti globali &quot;NLWS&quot;. Nell&#39;esempio seguente viene richiamato il metodo statico [PostEvent](sm-workflow-postevent.md) dello schema [xtk:workflow](s-xtk-workflow.md).

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## Metodi non statici

Per utilizzare i metodi non statici di SOAP, è innanzitutto necessario recuperare un&#39;entità utilizzando i metodi [load](f-load.md) o [create](f-create.md) negli schemi corrispondenti. Nell&#39;esempio seguente viene richiamato il metodo [ExecuteQuery](sm-querydef-executequery.md) dello schema [xtk:queryDef](s-xtk-querydef.md).

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## Limitazioni

Impossibile utilizzare alcune chiamate non statiche perché l&#39;oggetto caricato (\*\*) non contiene dati. È il caso, ad esempio, di alcune chiamate a [nms:delivery](s-nms-delivery.md).
