# esegui

Alias del comando execute. Questa funzione è obsoleta. Utilizzare [execute()](m-dbengine-execute.md)

```text
exec (command [, value1, ... ])
```

## Parametri

Comando SQL **comando**.

**valore1, ...** Variabili del comando.

## Valore restituito

Numero di registrazioni aggiornate o inserite se applicabile al comando eseguito, se diverso da zero.

## Funzioni

**Metodo di classe:** [DBEngine](c-dbengine.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
