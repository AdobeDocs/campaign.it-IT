# mkdir

Crea una directory con il percorso dell&#39;oggetto [File](c-file.md) corrente.

```text
mkdir ()
```

## Parametri

Nessuno.

## Valore restituito

Nessuno.

## Osservazioni

Se necessario, crea anche directory intermedie. Viene generata un&#39;eccezione in caso di errore.

**Metodo di classe:** [File](c-file.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
