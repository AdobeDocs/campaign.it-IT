# isSameNode

Verifica se il riferimento specificato rappresenta lo stesso nodo.

```text
isSameNode ()
```

## Parametri

Nessuno.

## Valore restituito

true se entrambi i riferimenti rappresentano lo stesso nodo, altrimenti false.

## Osservazioni

Questo metodo deve essere utilizzato per confrontare due riferimenti. Non è possibile utilizzare gli operatori JavaScript == e ===.
