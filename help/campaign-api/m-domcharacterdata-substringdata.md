# substringData

Estrarre una parte del testo.

```text
substringData (offset, count)
```

## Parametri

**offset** Posizione del primo carattere (0 per il primo carattere).

**count** Numero di caratteri da estrarre.

## Valore restituito

Stringa di caratteri estratta.
