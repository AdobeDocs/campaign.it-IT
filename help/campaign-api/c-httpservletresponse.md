# HttpServletResponse (classe)

Rappresenta la risposta di un servlet restituito a un client.

Esiste una sola istanza di questa classe accessibile dalla variabile `response`.

## Elemento “methods”

| Elemento “method” | Descrizione |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | Modifica il tipo di documento della risposta. |
| [inviaReindirizza](m-httpservletresponse-sendredirect.md) | Restituisce un reindirizzamento temporaneo a un altro URL. |
| [addCookie](m-httpservletresponse-addcookie.md) | Aggiunge un cookie alla risposta. |
| [addHeader](m-httpservletresponse-addheader.md) | Aggiunge un’intestazione HTTP aggiuntiva alla risposta. |
| [inviaErrore](m-httpservletresponse-senderror.md) | Restituisce una risposta di errore utilizzando il codice di errore passato come parametro. |

## Funzioni

**Disponibile in:**

* JSSP
* WebApp
