# insertBefore

Inserire un nodo prima di una posizione specifica.

```text
insertBefore (newChild, refChild)
```

## Parametri

**newChild** nodo da inserire.

**refChild** nodo secondario che deve seguire il nodo da inserire.

## Valore restituito

Nodo inserito.

## Funzioni

**Metodo di classe:** [DOMNode](c-domnode.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
