# GetAccessInfo

Restituisce le proprietà ereditate della modalità anonima.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Parametri

**categoryId** ID categoria

## Valore/i restituito/i

**anonimo** Specifica se le offerte della categoria sono anonime o meno

**parentAnonymous** Specifica se le offerte della categoria principale sono anonime o meno

**Schema:** [nms:offerCategory](s-nms-offercategory.md)

**Statico:**

Sì
