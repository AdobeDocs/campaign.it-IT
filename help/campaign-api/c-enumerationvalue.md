# EnumerationValue (classe)

Rappresenta la definizione di un valore di enumerazione.

## Proprietà

| Proprietà | Descrizione |
| --- | --- |
| [etichetta](p-enumerationvalue-label.md) | Restituisce una stringa di caratteri che forniscono la breve descrizione del valore di enumerazione corrente. |
| [descrizione](p-enumerationvalue-description.md) | Restituisce una stringa di caratteri che fornisce la descrizione del valore di enumerazione corrente. |
| [valore](p-enumerationvalue-value.md) | Restituisce una stringa di caratteri che fornisce il valore dell&#39;enumerazione corrente. |
| [nome](p-enumerationvalue-name.md) | Restituisce una stringa di caratteri che fornisce il nome del valore di enumerazione corrente. |
| [immagine](p-enumerationvalue-image.md) | Restituisce una stringa di caratteri che fornisce il nome dell&#39;immagine del valore di enumerazione corrente. |
| [enabledIf](p-enumerationvalue-enabledif.md) | Restituisce una stringa di caratteri che fornisce le condizioni di validità del valore di enumerazione corrente. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
