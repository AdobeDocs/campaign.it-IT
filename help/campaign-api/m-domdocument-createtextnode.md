# createTextNode

Crea un nuovo nodo di tipo testo.

```text
createTextNode (data)
```

## Parametri

**dati** Stringa di caratteri da inserire nel nodo di testo.

## Valore restituito

Nodo di tipo [DOMCharacterData](c-domcharacterdata.md) creato.

## Funzioni

**Metodo di classe:** [DOMDocument](c-domdocument.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
