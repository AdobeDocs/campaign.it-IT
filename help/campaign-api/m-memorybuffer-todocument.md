# toDocument

Restituisce un documento XML dal contenuto di testo di questo buffer.

```text
toDocument ( [codePage ])
```

## Parametri

**codePage** Numero intero che codifica la pagina dei caratteri utilizzata. Per impostazione predefinita, MemoryBuffer.CODEPAGE\_UTF8.

## Valore restituito

Oggetto di tipo [DOMDocument](c-domdocument.md).

## Funzioni

**Metodo di classe:** [MemoryBuffer](c-memorybuffer.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
