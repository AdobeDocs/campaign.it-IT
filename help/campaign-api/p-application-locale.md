# lingua

Restituisce una stringa di caratteri corrispondente all&#39;istanza Local.

```text
locale
```

## Osservazioni

Locale è un codice che definisce le impostazioni internazionali. È costituito da un codice lingua seguito da un codice paese, separato da &quot;-&quot;. Esempi di valori:

* en-US - Inglese, Stati Uniti
* en-GB - Inglese, Gran Bretagna
* fr-FR - Francese, Francia
* de-DE - Tedesco, Germania
* es-ES - Spagnolo, Spagna
