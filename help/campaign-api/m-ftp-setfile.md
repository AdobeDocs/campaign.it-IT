# setFile

> Avvertenza:
>
> L&#39;accesso tramite API di file è limitato alle cartelle **var**, **sftp** e temporanee di Adobe Campaign.

Definisce la modalità di trasferimento e il file di ricezione.

```text
setFile (filename)
```

## Parametri

**nomefile** Nome del file locale.

## Valore restituito

Nessuno.

## Funzioni

**Metodo di classe:** [FTP](c-ftp.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
