# DOMAttr (Classe)

Un nodo di tipo attributo.

## Proprietà

| Proprietà | Descrizione |
| --- | --- |
| [isId](p-domattr-isid.md) | true se l&#39;attributo è un tipo ID. |
| [nome](p-domattr-name.md) | Nome attributo. |
| [elementoProprietario](p-domattr-ownerelement.md) | Elemento con questo attributo o null. |
| [specificato](p-domattr-specified.md) | true se il valore è specificato in modo esplicito (per impostazione predefinita non è un valore implicito). |
| [valore](p-domattr-value.md) | Valore di testo attributo. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
