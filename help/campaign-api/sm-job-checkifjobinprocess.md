# CheckIfJobInProcess

Verificare se il processo è ancora in esecuzione

```text
Boolean result = CheckIfJobInProcess ( Number pid, String hostName )
```

## Parametri

**pid** identificatore processo

**hostName** Nome del computer in cui è stato avviato il processo

## Valore/i restituito/i

**risultato** risultato

**Schema:** [xtk:job](s-xtk-job.md)

**Statico:**

Sì
