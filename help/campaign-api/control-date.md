# Data

Un controllo di tipo data consente di immettere una data.

![Controllo data](assets/date.925e5185.png)

## Proprietà

**coloreIndietro - stringa** Colore di sfondo (btnshadow, bianco).

**bordo - stringa** Modifica lo stile del bordo durante il controllo (solido, doppio, interno, esterno, nessuno).

**font-size - integer** Modifica la dimensione del font.

**etichetta - stringa** etichetta associata.

**nolabel - booleano** Nasconde l&#39;etichetta associata.

**readOnly - boolean** Impone al controllo di sola lettura.

**obbligatorio - booleano** Il campo è obbligatorio.

## Osservazioni

È possibile utilizzare questo controllo per fare riferimento a un campo di tipo datetime per modificare solo la parte data. La parte ora verrà reimpostata su zero.
