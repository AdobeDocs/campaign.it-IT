# FileModifica

Questo controllo consente di immettere un nome di file.

![Controllo FileEdit](assets/fileedit.56228d2a.png)

## Proprietà

**coloreIndietro - stringa** Colore di sfondo (btnshasow, bianco).

**bordo - stringa** Modifica lo stile del bordo durante il controllo (solido, doppio, interno, esterno, nessuno).

**dlgType - string** Tipo della finestra di selezione file (save, opendir, savedir).

**filtri - stringa** Elenco di filtri

**font-size - integer** Modifica la dimensione del font.

**etichetta - stringa** etichetta associata.

**lastPath - string** Percorso della finestra di selezione dei file.

**loadContent - booleano** Carica il contenuto di un file.

**nolabel - booleano** Nasconde l&#39;etichetta associata.

**readOnly - boolean** Impone al controllo di sola lettura.

**obbligatorio - booleano** Il campo è obbligatorio.

**titolo - stringa** Titolo della finestra di selezione

**xpathCopyName - xpath** Percorso per l&#39;archiviazione del nome file (con la relativa estensione).

**xpathType - xpath** Tipo di file (testo o XML)
