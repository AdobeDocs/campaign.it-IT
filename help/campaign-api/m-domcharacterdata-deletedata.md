# deleteData

Elimina una parte del testo.

```text
deleteData (offset, count)
```

## Parametri

**offset** Posizione del primo carattere da eliminare (0 per il primo carattere).

**count** Numero di caratteri da eliminare.

## Valore restituito

Nessuno.
