# ResolvePackageReferences

Risolve le dipendenze nel pacchetto

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Parametri

**parametri** elemento XML contenente il pacchetto da importare.

## Valore/i restituito/i

**patchedPackage** Pacchetto elaborato.

**warningNb** Numero di avvisi generati.
