# NotifyValidation

Notifica di approvazione in una campagna.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Parametri

**deliveryId** Identificatore di consegna

Convalida targeting **target**

**contenuto** approvazione contenuto

**budget** Approvazione budget

**estrazione** Approvazione del file di estrazione

**FCP** approvazione bozza

**sandbox** Approvazione stima target

**edizione** Modifica contenuto

**esterno** approvazione contenuto esterno

Nessuno.
