# CheckAccess

Verifica se l’operatore corrente è in grado di accedere all’attività.

```text
Boolean result = CheckAccess ( XML taskEntity )
```

## Parametri

**taskEntity** entità attività

## Valore/i restituito/i

**risultato** Valore restituito dal metodo (sì/no)

## Funzioni

**Schema:** [nms:task](s-nms-task.md)

**Statico:**

Sì
