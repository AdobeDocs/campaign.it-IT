# BuildTableList

Ottiene un elenco di nomi di tabella.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Parametri

ID **dataSource** dell&#39;origine dati

**tablePattern** maschera per il nome della tabella

## Valore/i restituito/i

**elencoTabelle** elenchi di tabelle esistenti
