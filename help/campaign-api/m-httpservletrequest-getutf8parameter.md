# getUTF8Parameter

Restituisce il valore (codificato in UTF-8) di un parametro della query.

```text
getUTF8Parameter (name)
```

## Parametri

**name** Nome parametro.

## Valore restituito

Il valore del parametro richiesto.

## Funzioni

**Metodo di classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponibile in:**

* JSSP
* WebApp
