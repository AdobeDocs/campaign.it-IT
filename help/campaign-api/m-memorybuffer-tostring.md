# toString

Restituisce il contenuto di [MemoryBuffer](c-memorybuffer.md) sotto forma di stringa di caratteri.

```text
toString ( [codePage ])
```

## Parametri

**codePage** Numero intero che codifica la pagina di caratteri utilizzata. Per impostazione predefinita, MemoryBuffer.CODEPAGE\_UTF8.

## Valore restituito

Contenuto di un timbro sotto forma di stringa di caratteri.

## Funzioni

**Metodo di classe:** [MemoryBuffer](c-memorybuffer.md)

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
