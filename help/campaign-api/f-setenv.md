# setEnv

>[!WARNING]
>
>Questa funzione è disponibile per un ambiente locale.

>[!NOTE]
>
>È possibile disattivare questa funzione passando l&#39;opzione **XtkSecurity\_Disable\_GetSetEnv** a **true**.

Imposta il valore di una variabile di ambiente.

```text
setEnv (name, value)
```

## Parametri

**name** Nome della variabile di ambiente.

**Valore** Nuovo valore per la variabile di ambiente.

## Valore restituito

Il nuovo valore della variabile.

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
