# FTP (classe)

Un oggetto FTP consente di eseguire diverse operazioni utilizzando il protocollo FTP.

## Elemento “methods”

| Elemento “method” | Descrizione |
| --- | --- |
| [FTP](m-ftp-ftp.md) | Crea un nuovo oggetto per eseguire i comandi FTP. |
| [elimina](m-ftp-dispose.md) | Libera le risorse utilizzate dall&#39;oggetto. |
| [elenco](m-ftp-list.md) | Restituisce l&#39;elenco dei file sul server in una directory specificata. |
| [download](m-ftp-download.md) | Scarica un file dal server in un file locale o in memoria. |
| [carica](m-ftp-upload.md) | Scaricare un file da un file locale a un server FTP. |
| [setFile](m-ftp-setfile.md) | Definisce la modalità di trasferimento e il file di ricezione. |

## Funzioni

**Disponibile in:**

* Gestione dei contenuti
* Proprietà di consegna
* Regola di tipologia
* JSSP
* Metodo SOAP
* WebApp
* Flusso di lavoro
