# hasChildNodes

Verifica se il nodo dispone di almeno una sottocartella.

```text
hasChildNodes ()
```

## Parametri

Nessuno.

## Valore restituito

true se il nodo ha almeno un elemento figlio, altrimenti false.

**Metodo di classe:** [DOMNode](c-domnode.md)

* Proprietà di consegna
* Messaggio di consegna
* Regola di tipologia
* Importazione

* WebApp
* Flusso di lavoro
