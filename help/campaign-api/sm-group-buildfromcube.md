# BuildFromCube

Genera l’elenco in base a una selezione di celle da un cubo.

```text
BuildFromCube ( Number listId, XML conditions )
```

## Parametri

**listId** Identificatore elenco

**condizioni** Condizioni per definire la creazione di elenchi

## Valore/i restituito/i

Nessuno.

**Schema:** [nms:group](s-nms-group.md)

Sì
